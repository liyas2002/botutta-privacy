# Botutta

Botutta is an automated live-chat bot for a YouTube livestream.

It provides interactive live-chat features, games, viewer participation, and automated replies to improve the livestream community experience.

## YouTube Livestream

Botutta works with YouTube live-chat functionality through the YouTube Data API Services.
